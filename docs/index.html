Cross-Platform Ready

Fast, simple cloud infrastructure in Go.

Boyo is a CLI helper designed to rapidly prototype AWS environments without heavy configuration.

Download for Linux (x64) All Releases

Also available for: Windows (.exe) | macOS (Apple Silicon) | Linux

# Quick Install (macOS / Linux)
$ curl -sSL -o boyo https://github.com/ProjectLock/boyo-cli/releases/latest/download/boyo-linux-amd64
$ chmod +x boyo && sudo mv boyo /usr/local/bin/

# Run Boyo
$ boyo create -t webserver -r us-east-1
Loading AWS config for region 'us-east-1'...
EC2 Webserver launched successfully!
